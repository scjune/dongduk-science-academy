# 동덕여자고등학교 2026 과학심화진탐아 학술제 초대장

학부모님께 문자로 보내는 모바일 초대장입니다. GitHub Pages로 배포합니다.

## 내용 수정

발표자, 연구 주제, 날짜, 시간, 장소, 색상은 [공유 구글 시트](https://docs.google.com/spreadsheets/d/14lM-VAJaGQxx2yVUsN24H0MH-9aRV-yGePmfuf8Qx9k/edit)에서 고칩니다. 시트를 고친 뒤 초대장을 새로고침하면 반영되며, 코드를 커밋할 필요가 없습니다.

시트를 읽으려면 시트 공유가 "링크가 있는 모든 사용자: 뷰어" 이상이어야 합니다. 시트를 읽지 못하면 초대장은 `content.js`의 기본 내용을 표시합니다.

## 참석 확인

학부모님이 제출한 참석 여부는 초대장 내용 시트와 분리된 비공개 시트에 저장합니다. 이 시트는 링크 공개로 바꾸지 말고 담당 선생님만 편집자로 공유합니다.

`apps-script/Code.gs`를 비공개 시트의 Apps Script에 넣어 웹 앱으로 배포하고, 그 주소를 `content.js`의 `INVITE_RSVP_URL`에 적으면 양식이 나타납니다.

## 디자인 수정 후 배포

브라우저가 이전 파일을 저장해 두므로 `style.css`, `app.js`, `content.js`를 고치면 `index.html`의 `?v=` 값도 함께 바꿉니다.

## 파일

- `index.html`, `style.css`, `app.js`: 초대장 화면
- `content.js`: 시트 ID와 기본 내용
- `og.png`: 문자·메신저 링크 미리보기 이미지

## 바로가기 주소

- 공유용 첫 화면: `/?v=2026` (링크 미리보기를 바꾼 뒤 메시지 앱에 예전 미리보기가 남으면 이 값과 `og:url`을 함께 바꿉니다)
- 첫 화면: `/`
- 1학년: `/#1`
- 2학년: `/#2`
