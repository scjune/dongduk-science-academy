# 동덕 과학 심화 진로 탐색 아카데미 학술 발표회 초대장

학부모님께 문자로 보내는 모바일 초대장입니다. GitHub Pages로 배포합니다.

## 내용 수정

발표자, 연구 주제, 날짜, 시간, 장소, 색상은 [공유 구글 시트](https://docs.google.com/spreadsheets/d/14lM-VAJaGQxx2yVUsN24H0MH-9aRV-yGePmfuf8Qx9k/edit)에서 고칩니다. 시트를 고친 뒤 초대장을 새로고침하면 반영되며, 코드를 커밋할 필요가 없습니다.

시트를 읽으려면 시트 공유가 "링크가 있는 모든 사용자: 뷰어" 이상이어야 합니다. 시트를 읽지 못하면 초대장은 `content.js`의 기본 내용을 표시합니다.

## 파일

- `index.html`, `style.css`, `app.js`: 초대장 화면
- `content.js`: 시트 ID와 기본 내용
- `og.png`: 문자·메신저 링크 미리보기 이미지

## 바로가기 주소

- 첫 화면: `/`
- 1학년: `/#1`
- 2학년: `/#2`
